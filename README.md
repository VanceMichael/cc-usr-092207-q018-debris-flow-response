# 泥石流搜救态势板

汇总泥石流失联人员、搜索网格、队伍资源和权威通报。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括应急指挥人员、现场搜救队伍、家属联络人员、权威信息发布人员。

资料所依据的领域事实如下（截至 2026-09-19 深夜）：

- 局部强降雨在石家沟隧道附近引发泥石流险情
- 最初五名失联人员中已有两人被找到
- 其余三名失联人员的搜救仍在持续

共享资料自第二版起纳入以下运行规则：

- 灾害边界、气象地质警报、家属核验、搜索网格、队伍能力、车辆装备、进出记录与人员交接汇成实时态势
- 重复报警、坐标修正、再降雨停工、网格重搜和轮班只按顺序追加事件，不改写历史
- 弱网现场可领取签名任务并回传结果
- 家属联络岗位只看必要身份，新闻发布只引用确认状态
- 指挥员视图回答哪里已经覆盖、谁仍未确认、资源被谁占用、下一次通报凭什么发布

失联人员名单、搜索区域和对外表述必须随版本同步更新；版本过期的记录会被读取模块拒绝，防止队伍携带过期信息进入石家沟隧道附近的危险地带。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实、约束、态势快照、事件规则、弱网协同与岗位可见性。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
