# 泥石流搜救态势板

汇总泥石流失联人员、搜索网格、队伍资源和权威通报。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括应急指挥人员、现场搜救队伍、家属联络人员、权威信息发布人员。

资料所依据的领域事实如下：

- 局部强降雨在隧道附近引发泥石流险情
- 初步核实五人失联且后续已有人员被搜救发现
- 其余失联人员的搜救仍在持续

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
